## 🔍 关键词分类策略

### 1. 直接交友类 (高频)
**特点**: 意图明确���用户质量高
**使用频率**: 每天

#### 核心关键词
- `找对象` - 最直接，用户意图明确
- `相亲` - 认真程度高，适合长期关系
- `交友` - 范围较广，包含各类社交
- `脱单` - 紧迫感强，近期意愿强烈
- `征婚` - 最严肃，通常准备结婚

#### 变体关键词
- `找男友` / `找女友` - 性别明确
- `找男朋友` / `找女朋友` - 更口语化
- `蹲男友` / `蹲女友` - 年轻化表达
- `CPDD` - 游戏化相亲，年轻用户
- `征男朋友` / `征女朋友` - 传统表达

### 2. 状态声明类 (中频)
**特点**: 用户主动声明状态，意向较强
**使用频率**: 每2-3天

#### 关键词
- `单身` - 基础状态声明
- `单身交友` - 状态+意图
- `单身贵族` - 自嘲式表达
- `母胎单身` - 真诚度高
- `刚分手` - 可能是反弹期
- `空窗期` - 寻求新关系

### 3. 地理限定类 (高频)
**特点**: 结合地理位置，提高匹配精度
**使用频率**: 每天

#### 表达方式
- `{城市}找对象` - 直接明确
- `{城市}相亲` - 地理+严肃
- `{城市}交友` - 地理+社交
- `{城市}脱单` - 地理+紧迫
- `{城市}CP` - 地理+年轻化
- `坐标{城市}` - 社交风格
- `{城市}本地` - 强调本地化

### 4. 特定场景类 (低频)
**特点**: 特定时间或场景，时效性强
**使用频率**: 按需使用

#### 节日/季节
- `春节相亲` - 春节期间
- `情人节脱单` - 2月14日前后
- **过年相亲** - 春节前一个月
- **暑假交友** - 6-8月

#### 活动/场景
- `校友相亲` - 学校相关
- **公司交友** - 企业相关
- **同城活动** - 线下活动
- **网友见面** - 线上转线下

### 5. 人群特征类 (中频)
**特点**: 针对特定职业或背景
**使用频率**: 每周

#### 职业相关
- `程序员找对象` - 技术人员
- `金融女脱单` - 金融行业
- **互联网交友** - 互联网从业者
- **教师相亲** - 教育行业
- **医生找对象** - 医疗行业

#### 学历相关
- `硕士相亲` - 高学历
- `本科交友` - 大学生群体
- **留学生交友** - 海归群体
- **博士找对象** - 最高学历

### 成本效益
```

```
