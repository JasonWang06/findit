# 🚀 FindIt 智能爬虫系统使用指南

## 📋 系统概述

**FindIt 智能爬虫系统** 是一个根据时间和策略自动安排爬虫任务的调度系统，能够系统化地覆盖不同地理区域和用户群体。

### 核心特性

- ✅ **智��调度**: 根据星期几自动选择城市和关键词
- ✅ **分层策略**: 一线城市 → 新一线 → 国际市场
- ✅ **关键词优化**: 直接交友类 + 地理限定 + 场景化
- ✅ **性能优化**: 控制评论数量，提高爬取速度
- ✅ **灵活配置**: 支持自动、手动、测试多种模式

## 🎯 使用方法

### 1. 自动调度模式 (推荐)
```bash
# 根据当前时间自动选择城市和关键词
bash scripts/crawl_schedule.sh auto

# 自定义每个关键词最大帖子数
bash scripts/crawl_schedule.sh auto 15 5
# 格式: auto <最大帖子数> <每个帖子最大评论数>
```

### 2. 快速测试模式
```bash
# 单个关键词快速测试 (5个帖子，2条评论)
bash scripts/crawl_schedule.sh test
```

### 3. 手动指定模式
```bash
# 手动指定城市和关键词
bash scripts/crawl_schedule.sh manual "北京 上海" "找对象 相亲"

# 更多示例
bash scripts/crawl_schedule.sh manual "深圳" "CPDD 脱单"
bash scripts/crawl_schedule.sh manual "杭州 成都" "找男友 找女友"
```

### 4. 查看调度计划
```bash
# 查看完整的调度时间表
bash scripts/crawl_schedule.sh schedule

# 预览当前时间应该执行的任务
bash scripts/crawl_schedule.sh dry-run
```

## 📱 服务器部署

### 1. 设置服务器定时任务

```bash
# SSH 到服务器
ssh your_user@your_japan_server

# 编辑 crontab
crontab -e

# 添加以下任务 (每6小时执行一次)
0 */6 * * * /bin/bash /path/to/findit/scripts/crawl_schedule.sh auto >> /path/to/logs/cron.log 2>&1
```

### 2. 手动在服务器上运行

```bash
# 在服务器上运行智能爬虫
ssh your_user@your_japan_server "bash /path/to/findit/scripts/crawl_schedule.sh auto"

# 查看服务器当前应该执行的任务
ssh your_user@your_japan_server "bash /path/to/findit/scripts/crawl_schedule.sh dry-run"
```
